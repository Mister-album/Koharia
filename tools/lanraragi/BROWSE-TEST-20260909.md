# LANraragi 筛选、自动搜索、本地缓存与首图性能（2026-09-09）

## 改动

- 筛选改用 Komga 同款 AdaptiveSheet、CheckboxItem、SelectItem、TextItem、CollapsibleBox 和 SortItem，顶部保留重置与筛选按钮。编辑为草稿，点击筛选后应用。分组文案改为“合并显示合集”。Category 保留顶部分类，不在筛选面板重复显示。
- 搜索移除本地/服务端模式选择。联网自动使用服务端搜索，断网、网络异常或服务暂时不可达时使用完整本地缓存；鉴权、协议和业务错误不静默降级。服务器返回空列表仍显示空结果，不被本地旧结果替代。
- 输入采用 250 ms 防抖与取消，防止旧请求覆盖新查询。恢复网络时重新执行当前搜索。服务端结果在合集分组前匹配 archive，正确包含嵌套合集。
- 移除书架快照行；面向用户统一称为本地缓存。优先展示缓存，联网进入/返回书架时后台更新，一分钟内重复触发会合并；下拉刷新或菜单刷新主动更新。LANraragi 缺少通用增量目录接口，仍按完整批次原子发布，失败保留旧缓存与动态分类成员。
- 搜索状态下仅保留服务器切换按钮，给输入框留出空间。正文手动下载、临时图片缓存与书库元数据缓存仍分开管理。

## 首图慢的定位

用户反馈发生在阅读器已打开但首图尚未显示。此次使用独立模拟器测试包对官方 Demo 直接读取完整图片响应，不清除任何既有图片缓存、不写阅读历史或远端进度。

| 样本 | 页列表 | HTTP 响应头 | 完整图片传输 | Bitmap 解码 | 图片大小 |
|---|---:|---:|---:|---:|---:|
| Saturn 手册第 1 页 | 696 ms | 536 ms | 18,961 ms | 7 ms | 306,318 字节，1102×1940 |
| 同一作品第 4 页 | 同上 | 641 ms | 63,188 ms | 15 ms | 789,652 字节，2212×1940 |

本次 Demo 复现的主要瓶颈是图片响应正文传输，不能只根据 HTTP 200 或响应头耗时判断加载完成，也不能归因于阅读器解码。原始图片越大，等待越明显。其他私有服务器还需对应请求的计时，不能据此断言所有实例都由同一原因引起。

客户端同时消除了两处额外等待来源：

- 阅读图片与封面/目录使用独立 OkHttp 调度队列；连接重载和移除仍取消两个队列。测试证明封面队列饱和时，阅读图片可以发起并完成请求。
- 预览页暂停时停止创建图片请求，离开后的预览传输在读取时响应取消，避免继续与阅读器抢带宽。保留现有图片缓存，重复阅读继续复用缓存。

新增 `LanraragiStartup` 日志记录 sourceId、页序、响应头耗时、完整传输耗时、字节数及是否完整，不包含服务器地址、标题、API Key。配合已有 `MangaStartup` 的图片实际显示日志，可区分页列表、网络和阅读器阶段。没有通过降低图片质量或更改正文页序掩盖慢加载。
