# 官方 Demo 模拟器测试（2026-09-08）

## 环境与真实接口

- 地址：https://lrr.tvc-16.science/
- 客户端：本次工作区构建的 Koharia Debug。
- 设备：`emulator-5554`，Android 17，x86_64，16 KB 页大小。
- `/api/info` 返回版本 `0.9.81`、`nofun_mode=false`、`server_tracks_progress=false`、`authenticated_progress=true`。
- 无 API Key 即可读取目录与图片。本次不进行服务端进度或元数据写入。
- 归档接口实际返回 10 个有效归档，另有 1 个 Tankoubon 和 5 个分类。服务端公布的总数包含未返回元数据的条目，不能用总数代替实际可读取条目数。

## 发现并修复的问题

动态分类 `group:wadamemo` 的搜索响应报告 `recordsFiltered=3`，但 `data` 只有 2 个条目。
原来的客户端以 `data.size` 增加 `start`，下一次请求 `start=2` 会重复得到上一页最后一个条目，导致完整索引同步报 `INCOMPLETE`。

现改为读取 `/api/info` 的 `archives_per_page`，按服务端结果窗口推进 `start`。
有总数时允许跳过没有可用元数据的窗口；仍保留对异常重复整页的检查。
增加了“返回数量少于计数”和“空窗口后仍有数据”两个回归测试。

## 验证范围

最终结果：真实 Demo 模拟器集成测试通过，28 项 LANraragi 单元测试通过，格式检查与 Debug Kotlin 编译通过。
网络日志中针对 Demo 的 PUT、POST、PATCH、DELETE 请求数为 0。

使用 `LanraragiOfficialDemoTest` 验证实际 Source 与正式阅读/下载组件：

1. 创建无 Key 的临时 Demo 连接，测试版本探测和完整索引发布。
2. 校验归档、合集和分类，分别执行本地搜索与服务端搜索。
3. 展开真实合集的章节列表。
4. 选择 `Saturn Backup Cartridge - Japanese Manual`，获取并解码真实图片（共 7 页）。
5. 启动真实 `ReaderActivity`，等待页面 Ready，检查第一页、第二页和末页；日志确认三页均触发实际图片显示回调。
6. 通过现有下载队列下载这 7 页，关闭该连接的 API 后，用 `DownloadPageLoader` 读取本地文件并解码。
7. 确认隐身阅读没有产生连接进度记录；完成后清理测试连接及其文件、恢复临时修改的设置。

主界面启动会重置隐身模式，因此测试在阅读器验证完成后才启动主界面拍摄书库截图。
首次阅读导航引导在测试中临时关闭，结束时恢复，以免把引导或加载态误当成页面显示完成。

本次不能验收服务端进度回写：Demo 报告进度记录关闭，且进度更新要求身份验证。
公共 Demo 的内容和网络响应会变化；本次部分页面加载约 20–50 秒，测试使用页面就绪条件等待。

书库截图已人工检查，封面、合集和列表正常显示。正文截图因隐身模式触发 `FLAG_SECURE` 而被系统屏蔽，
没有将黑色截图当作正文渲染成功的证据；正文验证依靠实际页面就绪/显示回调及真实图片解码。

## 重跑

该测试必须显式启用，普通测试运行不会自动访问公共 Demo：

```powershell
$previousSerial = $env:ANDROID_SERIAL
try {
    $env:ANDROID_SERIAL = 'emulator-5554'
    .\gradlew.bat -PdeviceTestFixture=true :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=koharia.lanraragi.LanraragiOfficialDemoTest' '-Pandroid.testInstrumentationRunnerArguments.runLanraragiDemo=true'
} finally {
    $env:ANDROID_SERIAL = $previousSerial
}
```

日志与界面截图保存在本机 `app/build/lanraragi/`，不作为源码提交。
