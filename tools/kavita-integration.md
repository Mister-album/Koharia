# Kavita 原生接入：实现与验收记录

更新时间：2026-09-27。

本次变更已覆盖 P0–P4 的主要原生客户端入口，包括三类阅读、个人组织、批注和阅读增强。**完整版本、权限、内容及设备矩阵仍未验收完成，不能把所有阶段标记为完成或宣称已可正式发布。** 已对用户授权的 Kavita 0.9.1.4 服务器验证可写协议；公共 Demo 仅用于只读验证。

## 接入方式

在连接管理中新建 **Kavita**，填写名称、服务器地址和 Auth Key/API Key；也可粘贴服务器生成的 OPDS URL。保存前验证账号和最低版本。保留反向代理子路径；密钥不进入书籍、章节、封面或页面的持久化 URL。

连接设置提供浏览器入口。稳定身份由连接 ID、认证账号及服务器身份绑定：优先核对 installId、用户 ID、用户创建时间，旧版补充 JWT 声明。改名、密钥轮换和同一服务器地址切换保留书籍身份；更换账号取消旧会话。旧版无法返回足够服务器身份时，跨地址切换要求明确确认是同一服务器。旧版同地址被另一台同名账号服务器替换仍有识别限制。

书籍详情的 Kavita 菜单提供个人组织、评分、评论、关联作品、配置导入及 Kavita+ 入口。阅读器更多菜单提供个人目录和高亮批注；漫画页、EPUB 图片操作菜单提供远端收藏。选区创建批注，旧文件位置失效时可选择新原文创建重新定位的副本。共享阅读配置仅通过明确的预览确认导入。

## 缓存与同步

- 成功结果包含空结果，按连接、账号、筛选、排序和分页保存，无 TTL；启动/前台/网络恢复不主动刷新已有书架。
- 显式刷新暂存已加载页，全部成功后替换；失败保留旧数据。真实事件定向失效，进度事件独立处理。
- 离线搜索限定已下载内容，已保存筛选使用已缓存成员。不能由服务端平面筛选表达的 OR 与 AND 组合明确报错，不改变语义。
- 阅读事件先落本地；上传只确认对应修订，保留未解决冲突和显式未读。预加载、单纯打开章节不生成阅读写入。
- 漫画按服务器页序下载。单文件 PDF 可下载原文件；多文件 PDF 走页面下载和分页阅读，避免把 ZIP 当 PDF。
- EPUB 在线阅读不要求下载权限；主动整书缓存/下载重新检查角色，导出保持服务器页序和正文锚点的 EPUB。下载与嵌套资源请求使用独立调度器。
- EPUB 同步内容页和正文锚点；PDF 重排通过 source map 转换回原始页，不上传视觉页码。锚点失效时提示退回内容页。
- 手动下载、EPUB 缓存、漫画页面缓存、PDF 临时文件分开；清缓存不删除手动下载。
- 批注创建请求在发送前记录不确定状态；超时后核对远端匹配结果，不直接重复创建。迟到响应只确认相应修订，冲突保留双方。文件指纹确认替换后保留文字与注释，暂停旧位置上传。
- 书签使用远端章节、内容页与图片序号/目录标题建立身份，重试前核对服务器结果。从备份恢复的待上传书签需要确认；批注恢复不覆盖现存编辑或错误复用远端 ID。
- 删除目录书签前检查远端位置是否变化；冲突保留待同步操作，可显式取消对应修订的操作。文件替换后的批注刷新保留原文与笔记，包括远端已编辑或删除的情况。
- 名称搜索使用服务器文本匹配运算符，多库筛选使用列表包含语义；语言选项使用 ISO 代码。已保存的未知筛选字段保留，不能无损组合的 AND/OR 条件明确报错。
- 共享批注按服务器授权后分页；离线只浏览已缓存查询和分页。共享开关确认后更新服务端社交设置，不导入或覆盖本地阅读配置。
- Kavita+ 追踪状态只缓存白名单字段。服务端 Scrobble DTO 携带的第三方认证令牌和刷新令牌不会持久化。

## CBL 服务端异常处理

测试实例在列表成员已保存之后，封面合成触发 NetVips 异常，导致最终导入接口返回 HTTP 500。客户端不重放导入请求，而是核对唯一标题及完整有序的系列/章节成员；全部一致时提示“列表已保存，封面或元数据可能未完成”。部分保存或无法唯一确认时保留错误，供用户检查。该服务端封面问题尚未修复。

## 远端历史导入

现代接口按服务端分页完整读取阅读会话，按章节保留最近时间；0.8 使用旧版用户历史接口。旧版对未知 API 可能返回 HTTP 200 的网页，因此根据已认证版本选择旧接口，不将鉴权失败当成接口缺失。0.8 的时间来自进度行修改时间，无法提供现代阅读会话的 UTC 精度保证。

历史导入可建立尚未索引的系列与章节。远端写入采用数据库原子比较，仅推进阅读时间，保留本地阅读时长，不提交远端阅读进度。分页中途失败保留原缓存，成功空结果也是有效缓存。

当前 0.9.1.4 测试账号返回有效空历史，已验证接口和不写进度行为；这不构成真实非空阅读会话的验收。
