# Review 意见核实与处理

三项均确认存在，均修复；没有将可选创建、缓存浏览或原版阅读行为改为自动执行。

## 1. 补建另一类型书库

真实且可稳定触发：首次只启用书籍库后，已配置页面不再显示类型复选框，原先无条件跳过禁用类型又同时隐藏了添加按钮。

修复仅在新建向导中跳过禁用类型。已有连接保留另一类型的添加入口，必须主动添加并保存才启用。新加书库保存前、尚无目录或分配作品时可设置初始组织方式，已有默认书库保持只读。

## 2. 搜索取消影响已选系列

真实且可稳定触发：已选 A 后搜索 B，取消返回时搜索词未清空，而已选项从搜索结果中查询，导致 A 被当成未选择。

已选项改为从完整数据中按 ID、书库和目录解析；搜索词只过滤候选列表。仍阻止跨目录或跨书库的过期选择。

## 3. PDF 后台失败无限等待

真实，在后续解析或缓存写入失败时触发。此前后台只记录异常并关闭工作器，前台仍等待永远不会变为 true 的完成标志。

增加成功／失败终态，阅读器接收失败后结束准备状态并显示现有错误界面的重试和原版阅读入口。不会自动跳回原版阅读器；已生成分块及阅读上下文保留。主动取消不会被显示为准备失败。
