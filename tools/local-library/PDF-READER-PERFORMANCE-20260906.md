# PDF 阅读性能修复（2026-09-06）

## 修复内容

1. 缓存检查前不再显示重排弹窗。本地缓存按内容 SHA-256 验证后直接进入 Readium；缓存命中不再复制原文件或经过原版 PDF 页面加载。真实转换或远程原文件获取才报告准备进度。
2. 在已知首尾页拦截越界导航，避免 Readium 接收请求但不产生页码变化时，动画等待 1200 ms 加上 3800 ms 超时。阅读布局尚未准备好时消费输入，不启动截图动画。
3. 移除滑动后的 400 ms 补翻页。原生 R2WebView 完整处理手势与收尾动画；点击／按键仍使用配置的自定义翻页效果。
4. 跨资源动画以页码／布局变化为就绪信号，不再等待预加载页面不会再次发送的 onPageLoaded。PDF 图片分别打包成独立 XHTML，声明宽高以预留空间，并对邻近图片做有数量上限的空闲解码。
5. 后台分页扫描在阅读操作空闲后启动／推进；PDF 位置采集在滑动停稳后合并执行，减少重复 DOM 布局查询。

派生包版本升级为 `ir2:reflow4:epub3`，因此更新后的首次打开可能重新生成一次；同版本缓存命中应保持静默。

- 前后跨越图片页，确认没有固定停顿、空白闪烁或图片挤占正文。
