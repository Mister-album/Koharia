# PDF 注释重排与书库阅读器选择（2026-09-05）

## 实现

- 普通注音通过字形位置、字号比例和水平覆盖范围关联到底文，生成 XHTML ruby/rt；保留底文和注音各自的原始字符位置。正文排版前先合并注音组，避免小字进入正文行序。
- 上下标生成 sup/sub，参与正文行序但保留实际原坐标；英文单词补空格不再影响上标。
- 对同页可匹配的脚注编号和页底说明生成 noteref/footnote，注释资源独立于正文 spine，复用现有 Readium 注释处理与弹窗。没有匹配引用的页底文字继续保留。
- PDFium JNI 补充读取文字便笺、自由文本和常见文字标记的 Contents 与区域，生成可点击注释引用。
- 注音不再直接触发整页图片回退。几何关系明确冲突的注音区域提供局部原样回退，其余正文继续重排。旋转、多栏或大范围图文重叠等整页不可靠情况仍保留原页。
- 转换修订升级为 `pdfium-core-2.0.3:ir2:reflow4:epub2`，旧派生包不会冒充新结果。

## 书库选择规则

依据文件所属书库的配置，不依据当前选中的界面标签页：

| 所属书库 | PDF | EPUB | TXT/MOBI 与图片归档 |
|---|---|---|---|
| 书籍库 | 自动尝试重排；失败可继续原版 | 优先现有 Readium | 使用现有格式能力，文字格式沿用文本阅读设置 |
| 漫画库 | 默认原版漫画分页，可手动开启重排 | 图片型 EPUB 使用漫画分页；有正文时保留完整文本阅读能力 | 漫画分页设置；不强行把不可解析格式交给文本引擎 |
| 混合／未分类 | 保持原有按格式选择 | 保持原有行为 | 保持原有行为 |

本地源使用书架归属及根目录类型；Komga 使用启用的书库分类和 libraryId。远端文件无扩展名时由媒体类型辅助判断，媒体类型缓存进现有章节 memo，不涉及 SQL 模式迁移。

显式“原版 PDF”或“按页面打开”覆盖本次自动选择，避免往返循环。启动时的原 PDF 页码直接传入转换流程，避免被分页器初始回调覆盖；已读状态不再让自动重排强制从第一页开始。

远程 PDF 复用连接提供的原文件请求、身份验证与客户端。共享原有可取消传输辅助函数；原文件只在转换暂存目录使用。已知原文件指纹与转换版本相同时复用派生缓存，文件版本变化后重新转换。转换缓存不成为手动下载记录。

## 当前边界

脚注自动关联目前以同页匹配为主，跨页长注、复杂公式、复杂多层注音和 Tagged PDF 完整语义树恢复仍需扩展。批注位置用原页区域关联；几何推断不能保证所有排版的语义关系。远程行为通过受控响应验证，未连接实际 Komga 服务做在线权限与进度联调。原 PDF 云进度同步仍沿用前版所述限制，未将派生 XHTML 定位发送给原书。
