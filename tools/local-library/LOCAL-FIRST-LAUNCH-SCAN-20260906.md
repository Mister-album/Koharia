# 首次启动直接引导与新库首次扫描

## 行为

- 首次启动的导航栈直接以引导页作为当前页面，主页保留在下层供引导完成后返回，不先组合空书架再推入引导。
- 恢复的旧导航状态缺少引导时暂不渲染主页，补入引导后再显示；引导中的连接设置等子页面不会被打断。更新提示延后至引导完成。
- 新本地库首次保存配置后立即扫描一次，等待扫描完成再返回书架；扫描期间显示状态并禁用步骤切换。
- 配置保存和首次扫描完成协调处理，关闭页面造成的协程取消不会中断已开始的配置／索引收尾。
- 首次扫描失败时保留已创建的书库配置，并提示在书架手动刷新。之后保存已有配置或进入书架继续只读缓存，不反复自动扫描。

## 验证

- 格式检查、Kotlin 编译和 Debug 构建通过。
- 79 项单元测试通过，包含首次导航、已完成引导及恢复导航场景。
- 设备测试 18 项通过，1 项既有 SAF 用例因缺少专用目录授权而跳过。新增测试验证真实本地文件首次保存后已进入扫描索引、后续保存不扫描、外部新增文件需手动刷新，以及扫描失败不撤销配置。
