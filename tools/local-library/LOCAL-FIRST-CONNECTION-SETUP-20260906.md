# 首次本地库自动目录与组织方式必选

## 最新调整：可选启用与简化布局

- 新本地库最终保存后立即执行一次扫描，扫描结束再返回书架。首次启动直接显示引导；详见 `LOCAL-FIRST-LAUNCH-SCAN-20260906.md`。

- 第二步顶部只保留简短说明入口，点击进入系列库／单文件库详细说明页。
- 漫画、书籍标题前增加启用复选框，可以只启用一类；至少启用一类，且只校验启用书库的组织方式。
- 组织方式改为横向分段选择，下方显示当前选项的简短说明；默认不预选。
- 首个连接的自动目录创建延后至第二步点击下一步，只创建已启用类型的 Comics 或 Books 文件夹。返回修改后若增加启用类型，仅补建缺少的目录。
- 禁用期间保留草稿中的名称和选择，重新启用时恢复；最终保存排除禁用书库和目录绑定，防止配置迁移将其重新启用。已经存在的目录或文件不会因取消勾选而被删除。
- 本轮验证：76 项单元测试通过，设备测试 16 项通过、1 项既有 SAF 用例因缺少专用目录授权跳过。新增的单类型创建和补建测试通过。编译、格式检查通过，已安装至实机 `3ef7b819`。
- 日志：`artifacts/local-library-setup-options-build-final.log`、`artifacts/local-library-setup-options-device-tests.log`、`artifacts/local-library-setup-options-install-physical.log`。

手测：说明入口跳转；单独启用漫画或书籍；两个都取消时无法继续；分段选择显示和取消后重新勾选的状态恢复。

## 初版记录（启用及创建时机以最新调整为准）

- 数据目录直接复用引导中 `StoragePreferences.baseStorageDirectory` 保存的路径，不另行选择默认路径。
- 仅首个尚未配置且没有目录的本地连接自动创建 Comics、Books 和元数据目录；已有连接及后续连接不自动改动目录。
- 自动创建的目录分别绑定漫画、书籍默认书库，不扫描目录内容。
- 已有文件夹和有效清单会复用；遇到同名文件冲突不会覆盖，创建失败允许修复后重试。没有配置数据目录或缺少权限时不能直接完成初始化。
- 第二步顶部复用完整的系列库／单文件库说明；两个默认书库的选择初始均未选中，必须分别点击选择。翻页返回和页面重建后保留选择，最终保存也校验该条件。
- 保存后继续只读显示既定组织方式。书架仍仅显示扫描缓存，需要手动刷新才扫描。

日志：`artifacts/local-library-initial-setup-build-final.log`、`artifacts/local-library-initial-setup-device-tests.log`、`artifacts/local-library-initial-setup-install-physical.log`。
