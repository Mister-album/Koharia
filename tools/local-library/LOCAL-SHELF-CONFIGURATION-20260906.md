# 本地库改为由书库组织目录

## 新建规则

- 新建连接默认启用漫画库和书籍库，可用第二步标题前的复选框禁用其中一类；至少启用一类。
- 首个未配置的本地连接在第二步确认后，自动在应用数据目录下创建已启用类型对应的 Comics／Books 目录并绑定默认书库；失败时提供重试和重新选择数据目录入口。
- 创建流程为命名、配置书库、元数据设置三个步骤。第二步顶部提供说明入口，详细说明在二级页面展示。已启用书库使用横向分段控件选择组织方式，不预选；选择完成前不能继续或保存。
- 完成配置后默认书库组织方式只读显示。后续本地连接继续由用户在书库内配置目录。
- 已完成配置或已有目录的连接保留既有名称、类型、组织方式及根目录标识，不强制改为新默认值。

## 编辑结构

- 连接设置以书库列表为主要入口，不再列出独立的目录管理区。
- 打开书库后可编辑名称、组织方式、默认书库状态，以及该书库包含的目录。
- 添加或创建目录时继承当前书库的类型与归属，不再另选目录类型或目标书库。
- 点击已有目录可替换，移除按钮只移除配置。相同 SAF 目录通过不同层级树授权重复添加时会被拒绝；替换为原目录保留原标识及缓存。
- 配置草稿可在系统目录选择器返回或页面重建时恢复；最终保存前不会写入目录绑定。主动创建托管目录的操作会创建其目录结构。
- 移除或替换目录仅清理被移除根目录的扫描缓存和配置覆盖，不删除原文件；其他书库缓存保留。
- 已含目录或分配作品的书库锁定组织方式，避免改变现有作品归组和进度对应关系。
- 书架菜单入口改为“管理书库”。新本地库首次保存会立即扫描一次；之后编辑配置及进入书架不自动扫描，仍通过手动刷新更新。
- 书库编辑页标题下显示漫画库／书籍库类型；名称之后立即显示目录模块，组织方式移至目录模块下方。不可修改时只显示当前结果，不显示禁用的选项。

## 手测

1. 首次新增本地连接，确认自动出现漫画库和书籍库，并绑定应用数据目录下的 Comics、Books。第二步未选择或只选择一个默认书库的组织方式时不能继续，两者选定后可以继续。
2. 进入某个书库添加目录，确认目录仅出现在该书库内；添加多个目录、替换及移除操作均在书库编辑页完成。
3. 修改名称后点击确定返回，最终保存配置；重新打开确认配置保留。取消连接设置时不保存目录绑定变更。
4. 原有书库的目录归属应保持不变。修改配置后手动刷新书架，再检查新目录中的作品。
