# 本地书架文件删除

## 后续补充：移动与阅读状态

- 单项长按菜单、多选三点菜单均提供移动书库、标记已读、标记未读。
- 批量移动仅列出所有选中条目共同兼容的书库，保留现有内容类型及组织方式限制；更新书库归属，不改变原文件路径。
- 标记前同步本地章节，支持未打开过的书籍及整个系列。标记未读同时清除小说定位记录并重置章节阅读位置；操作后刷新书架进度与筛选结果。
- 批量操作失败项保持选中，可重试。
- 导入入口统一移入书架右上角三点菜单，移除独立导入按钮。
- 本轮验证：格式检查、编译、Debug 构建通过；63 项相关单元测试、12 项设备测试通过（包含上一轮删除回归及真实 SAF 用例，无跳过）。已覆盖安装至实机 `3ef7b819`。
- 日志：`artifacts/local-library-actions-build-final.log`、`artifacts/local-library-actions-device-tests.log`、`artifacts/local-library-actions-install-physical.log`。
- 手测：长按及多选菜单中的三项操作；未读后进度归零；移动后切换目标书库可见；从右上角三点菜单导入。

## 行为

- 本地书架长按菜单增加“删除文件”和“多选”，系列与单文件条目均可使用。
- 多选状态支持逐项选择、全选当前结果、取消选择和批量删除；网格与列表均显示选中状态。
- 确认框显示选中条目、相对路径及实际文件数，明确说明永久删除及阅读记录移除。
- 单文件条目只删除对应原文件，保留相邻元数据文件；图片目录条目只删除直属图片，保留目录、子目录及其他书籍；系列条目删除确认时列出的整个目录内容。
- 成功项移除数据库记录、关联阅读记录、封面缓存、本地索引、元数据覆盖和书架分配。批量失败项保持选中，并刷新可能已部分删除的目录。

## 文件保护

- 删除计划只能从当前来源的已索引书架条目生成；确认后重新验证根目录配置及目标文件。
- 禁止路径越界、子路径符号链接、系列递归涉及其他已配置书库根目录；不会删除书库根目录。
- 检查文件 URI、大小和修改时间；已变化的文件拒绝删除。普通路径允许已配置根目录的别名，但确认后别名改指其他位置会被拒绝。
- 目录在逐项删除后必须为空才移除，保留确认后新增的文件；普通文件路径使用非递归的 `File.delete()`。
- 文件操作与扫描互斥；确认后的删除和索引清理不会因关闭页面而在中途取消。

## 用户手测

请使用可删除的测试副本：

1. 长按条目，点击“删除文件”，检查名称、路径和文件数；取消后应保持原状。
2. 长按进入“多选”，勾选两本，确认选中高亮、全选和退出多选正常；批量删除后，文件与书架条目应同时消失，刷新不应恢复。
3. 分别测试单本、系列及图片目录；图片目录旁的其他书籍和子目录应保留。列表和网格模式的选择状态均应清晰。
