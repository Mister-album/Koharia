# 导入页面选择流程

- 书库与目录改为整块可点击的描边选择框，包含标签、占位提示和下拉箭头，明确表达可修改。
- 进入导入配置后先选书库，再显示目录选择；目录不自动选中，单个可用目录也需要明确选择。当前书架的书库仅在选项排序中优先展示。
- 目录按已选书库的导入兼容规则筛选，并优先列出其默认归属目录。目录选择保留已选书库，不再反向切换书库。
- 切换书库清除目录和系列选择，切换目录清除旧系列选择；导入按钮校验书库与目录的匹配关系。
- 系列目录使用“新建系列／已有系列”横向分段切换。新建时展示名称输入及元数据提示；已有时展示可点击的系列选择框，进入既有搜索列表。单文件目录不显示系列选项。
- 只存在一个可用本地连接时不再展示多余的连接切换项；导入期间禁用选择控件。

验证：格式检查、Kotlin 编译、Debug 构建和 107 项相关单元测试通过。新增测试覆盖书库优先、目录必选、位置切换重置系列，以及过期系列不可继续导入。已更新虚拟机和实机 `3ef7b819`。

手测：选择框可点击性与布局；先书库后目录的交互；切换目录后旧系列清除；系列两种模式的展示和导入。
