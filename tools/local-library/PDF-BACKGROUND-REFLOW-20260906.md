# 自动 PDF 重排的后台呈现

> 更新：下文“保留原版内容等待衔接”的过渡方式已被 `PDF-NOVEL-STARTUP-20260906.md` 替代。当前首次转换直接使用小说阅读器加载界面。

- 自动重排不再显示转换进度弹窗或前台转换计数；当前原版内容保持可读，使用 EPUB 风格的阅读工具栏，底栏及阅读指示器仅显示阅读位置百分比。
- 手动触发的重排保留原有进度与取消入口。
- 自动转换完成后，等待读取界面恢复到前台且用户停止操作，再采用当时的原 PDF 页位置衔接 Readium；切换章节后不会跳回旧章节。设置面板、对话框和正在触摸时不切换。
- Readium 分页计算期间继续显示百分比；完整分页结果或有效的完整分页缓存可用后才显示准确页数。
- 自动失败或产物已被清除时保留原版阅读，不弹出转换失败提示。

验证：spotlessApply、spotlessCheck、compileDebugKotlin、assembleDebug 通过；138 项相关单元测试通过。新增覆盖后台阅读位置更新、不同章节结果丢弃、百分比显示及准确页数显示条件。

按用户要求，未操作实机或继续录屏。手测重点：未缓存 PDF 自动重排不弹窗；期间翻页后不回退位置；后台或设置面板中不会被强行切换；分页完成后恢复页数。
