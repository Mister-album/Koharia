# PDF 自动重排入口修正

此前自动重排在漫画阅读器内进行，导致准备期间显示原版分页。本次改为首次转换和缓存命中都直接进入 EpubReaderActivity，由小说阅读器的初始化流程准备派生 EPUB。

- 首次转换使用现有 EPUB 加载界面，无转换进度弹窗；完成后在同一阅读器中显示正文。
- 分页未完成时显示阅读百分比，完整分页结果可用后显示准确页数。
- 保留原 PDF 页定位；取消初始化遵循协程取消，不再异步切回其他阅读界面。
- 失败时留在小说阅读器，提供用户主动打开原版的选项。
- 兼容旧自动重排入口，转发前不创建漫画页面视图；显式原版阅读保持原路径。

验证：格式检查、编译、调试包构建和 138 项单元测试通过；新增的冷启动／缓存启动入口设备测试通过，覆盖本地文件准备、阅读位置参数、兼容入口与显式原版入口。视觉效果交由用户手测。
