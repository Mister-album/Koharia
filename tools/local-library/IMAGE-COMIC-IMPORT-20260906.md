# 普通文件导入与图片合并分离

## 当前行为

- 普通导入使用书籍／漫画文件 MIME 筛选，排除散图；解析阶段优先识别真实图片头，避免改成 PDF 等扩展名后继续作为书籍导入。
- 混入散图的普通导入会明确提示使用独立图片合并入口，不静默丢弃图片。导入目标及实际写入端也排除图片扩展名。
- 阅读器支持列表与导入白名单分离，目录扫描、图片目录阅读、封面选择及已有的单图直接打开能力保留。
- 书架三点菜单新增“图片合并为漫画”。至少选择两张支持的图片，默认按文件名自然排序；可预览、上下调整页序、移除条目、修改漫画名称。
- 合并生成 CBZ，按确认顺序写入固定序号页名，保留原始图片字节，不缩放或重新编码。生成后进入现有导入配置页，按漫画库格式与组织方式选择目标。
- 中途失败或取消会清理临时包；导入完成或退出导入页也清理生成的临时文件，不删除原始图片。单次生成包限制为 2 GiB 图片数据。
