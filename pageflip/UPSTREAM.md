# Android PageFlip

This module contains the Java page-flip engine from
[`eschao/android-PageFlip`](https://github.com/eschao/android-PageFlip), fixed at commit
`6c361e0932c80c360fdf5f7de06963031e8c26d2`.

The upstream code is licensed under the Apache License 2.0. The original source headers are
preserved, and a copy of the upstream license is included as `LICENSE`.

Only the engine sources are included. The old sample application and its Android Support Library
dependency are intentionally excluded.
